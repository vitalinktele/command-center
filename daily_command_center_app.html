CONNECT YOUR APP

Follow these 3 steps to get cross-device sync. Takes about 3 minutes. Everything is free.

1
Create a free Supabase account
Go to supabase.com → click "Start your project" → sign up with GitHub or email (free, no credit card).

Then create a new project. Name it anything, e.g. daily-command-center. Choose a region close to you (e.g. US East). Set any database password and save it somewhere.
2
Create the checklist table
In your Supabase project → click SQL Editor in the left sidebar → click "New query" → paste this and click Run:

CREATE TABLE checklist (id TEXT PRIMARY KEY, checked BOOLEAN, date TEXT);

Then go to Authentication → Policies and enable Row Level Security, then add a policy to allow all (for personal use).
3
Paste your project keys below
In your Supabase project → go to Settings → API. Copy your Project URL and anon public key, then paste them here:
4
Add to your iPhone home screen
After connecting, host this file on Netlify (free): drag and drop your file at netlify.com/drop → get your live URL.

Then on iPhone: open the URL in Safari → tap the Share button → tap "Add to Home Screen" → tap Add. Done — it'll appear on your home screen like a native app.
💡 Pro tip: Once added to your home screen, the app works offline too. Any checks you make while offline will sync automatically when you reconnect.
